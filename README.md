# Hi, I'm Talha 👋

Computer Engineering student (Abdullah Gül University, 2022–2027) with a background in Industrial Automation & Mechatronics. Currently active both in industry and in my own startup.

### 🛠 What I'm working on

- **Kitt** — a blockchain-based traceability platform for industrial hemp exports to Europe. I'm the Technical Team Lead, working on the digital product passport interface, a Three.js scroll-driven 3D hero animation, and supply chain data.
- **IT Technician @ NURİŞ Teknoloji A.Ş.** — corporate IT infrastructure and systems support.
- Integrating Claude Code and AI-assisted development workflows into my daily work (MCP integrations, automation scripts).

### 🎓 Past project

**Clear Cart** — an AI-powered product recognition system using computer vision, barcode scanning, and embedding-based search. Backed by TÜSİAD, Tech Istanbul, and JA Startup; as technical co-founder I built an EfficientNet-B4 embedding extraction service (HuggingFace Spaces) and a Node.js/PostgreSQL backend with pgvector.

### 🌱 Interests / currently learning

- Blockchain-based traceability systems
- Network security & cryptography (TLS 1.3, Signal Protocol, X3DH, Double Ratchet, PQXDH)
- Vector search & embedding-based retrieval (pgvector, HNSW)
- Backend architecture: FastAPI, PostgreSQL, Docker, Nginx

### 💬 Ask me about

- Kitt's blockchain traceability architecture
- Clear Cart's embedding-based product search system
- Claude Code / AI-assisted development workflows
- Network security & cryptography
